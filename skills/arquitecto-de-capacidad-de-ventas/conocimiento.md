# CONOCIMIENTO — ARQUITECTO DE CAPACIDAD DE VENTAS

## Frameworks / Marcos mentales
- "Casi todo se resuelve con ventas" (margen + frecuencia + quién opere).
- Input vs output: puedes fallar el resultado, no el esfuerzo.
- Ventas = proceso entrenable, no talento estático (Messi entrena).
- El talento de ventas es infinito; el fundador no es el mejor vendedor posible.

## Tácticas y métodos
- Romper las 2 creencias limitantes del fundador: "solo yo puedo vender" / "soy el mejor vendedor".
- Cuenta de capacidad: fundador 10 h/sem → top vende 40 h/sem = 5x capacidad.
- Construir capability: reclutar + entrenar + formar + escuchar, e iterar.
- Subcultura de ventas con estándar de actuación explícito.
- "Hijo del alcalde": fichar a quien ya trae el network (abre toda la red de golpe).
- Automatizar parte del proceso con agentes/IA (handoff al Escuadrón A).

## Datos duros / Cifras (caso Rappi)
- En Rappi, ventas fue siempre "muy crack" aun cuando el resto del skill era bajo al inicio.
- "Hijo del alcalde": el restaurantero que conoce a todos; el practicante nieto del dueño de un banco que abrió reuniones con CEOs/chairmen de 15 bancos.

## Frases clave / Ejemplos
- "Casi todo se resuelve con ventas."
- "Podés fallar en el output, pero no en el input."
- "¿Has visto cuánto entrena Messi? Eso es ventas."
- "Conseguíte al hijo del alcalde."

## Antipatrones
- Creer que el fundador es el único o el mejor vendedor.
- Tratar las ventas como talento fijo en vez de proceso entrenable.
- Permitir fallar el esfuerzo (input).
